## About the portfolio

The portfolio was built to present my work and development journey in one place. It includes:

- **Introduction:** a short presentation, CV download and social links.
- **About me:** my background, approach to development and areas of interest.
- **Skills:** technologies and tools I have worked with.
- **Projects:** selected applications and games, with links to live demos and source code where available.
- **Experience:** a timeline of my professional journey.
- **Contact:** contact details and a form powered by EmailJS.

## Run locally

### Requirements

- [Node.js](https://nodejs.org/) (with npm)
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/PedroHQCoelho/pedrohqcoelho-portfolio.git
   ```

2. Open the project folder:

   ```bash
   cd pedrohqcoelho-portfolio
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in the terminal.

### Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Starts the development server. |
| `npm run build` | Creates the production build in `dist/`. |
| `npm run preview` | Previews the production build locally. |
| `npm run lint` | Runs Oxlint. |
